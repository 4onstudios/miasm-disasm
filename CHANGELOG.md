# Changelog

## 0.1.0

- Rust library and CLI using Miasm through an embedded JSON bridge.
- PE32/PE32+, ELF, and raw input; CFG and linear disassembly modes.
- Text, JSON, and Graphviz DOT output with instruction bytes and virtual addresses.
- Direct-call traversal, analysis budgets, timeouts, and structured errors.
- Reproducible sample binaries, integration tests, and pinned Python dependencies.
