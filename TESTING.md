# Release validation

Validation environment: Linux x86-64, Rust/Cargo 1.85.0, Python 3.12.14,
and Miasm commit `3671fc24d6e625c2d75f3311724eb6b0c97664f8`.

## Automated checks

`cargo test -- --include-ignored` passed all 19 checks:

- 4 Rust library unit tests.
- 2 CLI parsing unit tests.
- 12 integration tests invoking real Miasm through the Rust subprocess interface.
- 1 compiling Rust documentation example.

The integration suite covers PE32, PE32+, ELF64, x86-64 raw input, AArch64 raw
input, branch and direct-call traversal, overlapping-block splitting, custom
virtual addresses, instruction/block budgets, timeout termination, malformed
PE files, unmapped start addresses, Unicode/space-containing paths, JSON output,
partial-result exit codes, and refusal to overwrite output files.

The normal `cargo test` run leaves the 12 integration tests ignored because
they require an installed Miasm environment. To reproduce the full test run,
install `python/requirements.txt`, set `MIASM_PYTHON`, then use
`cargo test -- --include-ignored`.

Rustfmt formatting checks passed. Clippy checked all targets with warnings
denied. In this restricted build environment, rustfmt needed an explicit
thread stack, and Clippy was invoked through `clippy-driver` because the normal
launcher requires `/proc/self/exe`. These are test-runner adaptations outside
the delivered source; standard toolchains can use the README commands.

## Executable smoke checks

The completed Rust CLI produced the checked-in `examples/sample64.txt`, `.json`,
and `.dot` outputs: 9 instructions and 5 basic blocks, with both conditional
branch targets recovered. Missing Python dependencies and input files exceeding
64 MiB were also rejected as expected. The platform `file` utility independently
recognized the PE32, PE32+, and ELF fixtures.

`cargo build --release` and `cargo package --locked` passed. Link-time
optimization is disabled in the release profile after a thin-LTO linker
failure with this toolchain; ordinary release optimization remains enabled.
The Cargo packaging step extracts the `.crate` archive and rebuilds it. The
delivery ZIP includes that verified `.crate` archive in `dist/`.

## Scope

The examples are synthetic files generated by `scripts/make_fixtures.py`.
No user-supplied or third-party application was analyzed. No fixture was
executed as a program. Windows/macOS host execution and architectures other
than x86-32, x86-64, and AArch64 have not been tested. Graphviz DOT output was
generated and checked structurally; the Graphviz renderer was not installed.
